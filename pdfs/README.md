# Acceso a PDFs

Este proyecto no conserva PDFs locales. Todos los botones del sitio abren directamente el syllabus correspondiente en `https://istqb.org/`.

Las subcarpetas se mantienen como referencia de la estructura original, pero no deben contener PDFs. Consulta `../pdf-url-review/urls-pdfs.csv` para las URLs oficiales, versiones y fecha de revisión.
